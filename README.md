## What it does

`main.py` (Python 3.13, no network, no dependencies) writes a single
one-line joke about working beside AI coding agents to
`<MAKEFUN_OUTPUT_DIR>/entry.txt` (default `/output/entry.txt`).

## The joke

> My AI coding agent fixed the demo bug live in four seconds, then spent forty
> minutes breaking its own fix — then asked if I'd like it to continue.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
